배경음악(BGM) 파일 넣는 곳
==========================

이 폴더에 음악 파일을 bgm.mp3 라는 이름으로 넣으면
2th5.html 의 오른쪽 아래 "♪ 음악 켜기" 버튼으로 재생된다.

파일 이름을 바꾸고 싶으면 2th5.html 의 아래 부분을 같이 고친다.
    <audio id="bgm" src="bgm/bgm.mp3" loop preload="auto"></audio>


저작권 걱정 없이 받을 수 있는 곳
--------------------------------
1. 유튜브 스튜디오 > 오디오 보관함
   - 유튜브 계정만 있으면 무료. "저작자 표시 필요 없음" 으로 걸러서 받으면 편하다.

2. Pixabay Music : https://pixabay.com/music/
   - 무료이고 출처를 적지 않아도 된다. 학교 과제용으로 가장 간단하다.

3. Free Music Archive : https://freemusicarchive.org/
   - 곡마다 라이선스가 다르다. CC0 나 CC BY 곡을 고른다.

4. Incompetech : https://incompetech.com/music/
   - CC BY 라서 출처를 반드시 적어야 한다.


출처를 적어야 하는 곡(CC BY)을 쓸 때
------------------------------------
2th5.html 의 푸터에 이런 줄을 넣는다.

    음악 : 곡 이름 - 만든 사람 이름 (CC BY 4.0)


주의
----
- 가요, 애니메이션 OST, 게임 음악 같은 상업 음원은 넣으면 안 된다.
- 유튜브 영상에서 소리만 뽑아 쓰는 것도 저작권 문제가 생긴다.
